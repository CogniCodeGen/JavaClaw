# ADR 0005：H2 data-v5 与 Rollout

- 状态：Accepted
- 日期：2026-09-01

## 背景

Core、Item/Event/Outbox 与内置扩展状态需要原子提交，同时还需可验证的离线审计格式。在线数据库与导出文件承担
不同职责。

## 决策

App Server 独占 H2 `data-v5`。Core 从单一 baseline 初始化，每个内置扩展拥有独立 schema history，通过
`ManagedExtensionStore` 参与平台事务。第三方扩展只使用配额 document/blob API。Rollout 是带 sequence、哈希链和
manifest 的只读 JSONL 导出，不支持导入。

## 结果

在线状态只有一个写源，扩展 schema 所有权清晰。导出可校验和 replay，但不能用于恢复写入；备份属于发行/运维层
的独立能力。
