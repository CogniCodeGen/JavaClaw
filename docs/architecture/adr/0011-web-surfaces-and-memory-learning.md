# ADR 0011：受控 WebView 展示与工作空间记忆学习

日期：2026-09-07；更新：2026-09-08。状态：已实现，本机分段完成全模块门禁及定向功能验收；跨平台发行验收待执行。
最新测试与平台结论见[审查修复验收](../../evidence/chat-webview-memory-v3-review-fixes-validation.md)，
此前记录保留在[功能与 UI 对比验收](../../evidence/chat-webview-memory-v3-functional-ui-validation.md)。

## 决策与边界

聊天正文、只读文档与记忆图谱使用 JavaFX WebView；窗口、导航、输入框、审批和编辑表单继续由 JavaFX
承担。沿用 `509f197` 的布局与 CSS 令牌，通过主题探针向页面传递实际颜色和字体。Desktop 的所有业务读取、
写入和通知仍经 SDK；WebView 不连接 App Server，不打开工作区文件，不持有数据库或权限对象。

版本固定为 JDK 25、JavaFX 26.0.2、CommonMark 0.30.0、highlight.js 11.11.1 和 Cytoscape.js 3.33.1。
Markdown 采用 CommonMark 与项目自有宿主实现，未引入 JavaFX-Markdown-Preview。前端依赖以静态文件、
许可证和摘要清单随安装包发布，运行时不依赖 Node、CDN 或在线页面。服务端与 Desktop 使用相同的
Tables、Strikethrough、Autolink 扩展，保证 `link:N` 的含义一致。

## 消息状态与页面恢复

公开消息流保存在现有 Core Event 日志中；同步 `ModelEventSink.publish` 的返回仍意味着持久化完成。
50ms 批处理发生在已提交事件的通知与展示阶段，不以异步队列代替持久化契约。公开流不包含 reasoning、
Provider opaque state 或工具参数。模型调用身份、预留消息 ID、事件 cursor、SDK 已应用 cursor 与页面绘制
revision 相互独立。

SDK 的有界归并状态是页面恢复来源。连接内缺口重订阅、连接重建与页面重建均不重新执行 Turn；历史查询返回
有界摘要及完整内容引用，避免把超大 `ItemEnvelope` 截断后冒充原始事实。关闭或失败的调用和 Turn 终态都有
独立持久记录。正常 Harness 提交和直接取消立即唤醒订阅；其他终态的提交可由周期水位发现。

会话导航只结束当前展示观察，不取消服务端 Turn。重复选择幂等；历史、启动回执与终态结果必须同时匹配
导航代次、SDK 实例及 Thread。返回会话时从权威历史的 TurnId 经 `turn/read` 复核后恢复观察，不再次启动。
活动状态尚未恢复或恢复失败时禁止发送，失败可通过明确重选重试。旧协议仅有向前分页，需在有界时间及
内存内确认末尾；无法确认时明确失败，不能将截断结果当作无活动 Turn。

服务端订阅只借用连接，不拥有共享 RPC 的生命周期。退订以关闭标记与唤醒协作退出，不中断可能正在写入
SocketChannel 的线程；已在途通知允许完成，后续通知停止，原五秒发送硬截止继续约束失去响应的客户端。

`WebSurfaceHost` 将加载成功、桥接 ready、绘制 ack 分开处理。桥对象由 Java 强引用持有，回调必须匹配
页面代次、业务上下文和 revision。可见状态超时后自动重建一次，再显示原生简版；隐藏期间不累计绘制超时。
本机制处理页面加载及脚本故障，不承诺从 WebKit 原生进程级崩溃中恢复。

宿主保存不超过 2KiB 的展示阅读锚点，包含跟随状态、消息身份及相对位置；接收时检查代次、上下文及版本，
切换上下文清空。重建仅恢复展示，不重放业务命令。原生简版保留历史入口和未提交正文，用户主动向上阅读时
暂停跟随，明确返回最新后恢复。

`WebSurfaceRuntime` 在首次加载前创建进程独占的随机临时 WebKit profile，同 JVM 的页面共享该 owner，
避免独立进程争用默认目录造成白屏。正常关闭先释放页面，再尽力删除本 owner 创建的路径；不扫描其他目录、
不跟随符号链接，也不强制解锁。强制退出或系统锁延迟释放可能留下由 OS 管理的临时目录。

## 文档授权、版本与资源

文件引用必须提供来源 Item 与稳定选择器。App Server 从持久消息、受支持的 Coding 工具结果或文件变更
推导实际路径；客户端不能指定执行根、PermissionProfile 或临时授权。历史 Turn 的冻结限制与当前权限取交集，
句柄续用不能因后来扩权而扩大读取范围。相对资源必须真实出现在父文档中；独立附件只能引用同一条来源消息
明确携带且名称唯一的附件，不能推测工作区同名文件。

当前工作区文件通过现有原生隔离 Worker 流式复制到服务端受控缓存，附件经 Blob 的真实分块读取建立快照。
缓存预留覆盖创建中的文件，全局 128MiB、单来源 64MiB、每连接 8 个句柄；失败重试与关闭也不能提前释放仍由
Worker 使用的空间。快照在连接内拥有独立身份和五分钟闲置租约，每次读取或续租重新校验来源及权限。
关闭屏障覆盖缓存预留之前的来源读取及实时权限核验：先封入口并取消，再等待所有已入场操作归还所有权。
单个缓存删除失败不阻止其他句柄取消和回收，未能删除的内容仍占用预算，错误在完整清理尝试后汇总。

`document/preview/invalidated` 复用当前连接既有的有界通知队列，只携带句柄与固定原因。客户端清除对应的
正文和图片；重连会关闭旧预览，用户再次打开时重新解析来源。旧附件整包读取保留，新 metadata/readChunk
方法不提高 RPC 帧上限。

预览 resolve 完成后直接安排 FX 线程接管句柄；当前 epoch 才能接收，过期及关闭状态立即释放。
后台读取只能在所有权接管后启动，取消排队读取不能吞掉句柄的回收责任。清空或撤权先丢弃旧 WebView 及其
纹理，再恢复空展示，避免 DOM 清空已经确认但旧 WebKit 纹理仍显示正文或图片。

续租结果还需匹配具体续租请求和 handleId。相对导航开始即撤销父续租归属，解析期间不续租父版本；
迟到的父成功或失败不能阻塞子文档续租，也不能将当前正文换回父文档。

## 定时任务、取消与记忆

继续使用 Schedule Definition、Occurrence、Extension Job、Outbox 与既有 Supervisor。学习通过受限内部
绑定端口维护自己贡献的 Definition；所有者由组合根绑定，公共扩展 RPC 不能伪造 `binding/apply`。
重新绑定保留用户编辑的调度名称、时间和启停；删除后的 generation 防止旧协调意图复活任务。

活动 Job 的取消意图独立持久化，不能修改其执行 revision 并阻止真实工作单元结果提交。协作取消信号在意图
提交后发送，重启时重新读取；已完成的回执保留，未知结果保留待处理证据，不伪造取消成功或自动重试模型。

学习默认关闭。启用后按工作空间、固定证据上界与批次游标读取已完成的公开对话；学习自身输出从通用证据索引
排除。一次学习使用有界预算、空工具目录和一次模型 Turn。模型调用在事务外，候选提交、冲突、有效性与游标
在 Memory 自己的事务内处理；工作空间 head 防止并发发布覆盖已经变化的记忆。

有效性 sidecar 保留旧 Memory DTO。被替代或不满足时间范围的记忆不进入当前检索，自然语言条件只供人工
判断。旧搜索只返回当前有效的无条件记忆；旧写入口不能清除新条件或重新激活被替代记忆。

## 兼容与验收

学习配置的目录初选使用 `ViewInitialSelection` v1，放在 `ViewQueryResult.values["view.initialSelection"]`，
携带所属数据源、行键、版本字段名和精确 revision。它只影响当前页面首次展示：客户端核验已加载目录的键与
版本，显式选择或清空优先；失效、未加载、未知版本及损坏提示均保持未选，不自动替换为首行或 latest。
原引用与说明由普通声明式节点显示。元数据不参与业务命令绑定，不授予权限，保存仍由服务端复核。
旧服务端没有提示时保留既有主从页面默认行为，不增加 RPC 或 DTO 字段。

冲突参与者按同作用域、标签关系及 ACTIVE 语义状态统一筛选，时间有效范围不等于被替代状态。
新的删除操作在同一事务内拒绝仍被 PENDING 冲突引用的记忆；旧墓碑通过现有历史接口恢复展示和存储 revision。
KEEP_EXISTING 可以拒绝候选并关闭过时冲突，不复活参与者；其他决议仍要求当前 ACTIVE 记录。
Workspace head、conflict revision 和完整参与者版本集合共同执行 CAS 校验。

保留 Protocol v3、data-v6 和 14 个模块；数据库仅新增 V005–V007 前向迁移，不修改历史 migration。
新流、文档预览与图谱浏览元数据经能力协商。图谱浏览状态属于 Desktop 页面实例，不写入工作空间共享的
浏览会话；旧客户端仍可读取基础 Graph。代码必须通过原有格式、契约、架构、覆盖率、Golden 与发行门禁。

本机测试不能替代其他 Runner 的原生、字体、输入法、DPI、安装和签名验收。性能目标也不能替代测量；在有
真实对照数据之前，不声称 WebView 比原 JavaFX 聊天实现更快。未完成或未验证项目写入当前验收记录。
