# ADR 0001：平台与模块边界

- 状态：Accepted
- 日期：2026-09-01

## 背景

平台需要同时承载模型、工具、数据、桌面与可扩展业务。没有编译和进程边界时，基础设施依赖会进入执行内核，
客户端也容易绕过协议直接读取内部状态。

## 决策

使用 14 个 Maven 模块表达稳定契约、实现职责和独立进程。App Server 是唯一组合根和 H2 owner；Desktop 只依赖
SDK；Harness 生产依赖只允许 Core API 与日志门面。接口只用于模块边界、可替换实现和外部副作用。

## 结果

依赖方向可以由 Maven、JPMS 与架构测试检查。新增能力应进入扩展或 Adapter，而不是增加万能平台 Service。模块数
只有在出现真实编译或进程边界时才能增加。
