# 聊天、文档与后台记忆使用说明

本轮实现的设计边界见 [V3 计划](proposals/chat-webview-memory-v3.md) 和
[ADR 0011](architecture/adr/0011-web-surfaces-and-memory-learning.md)。本机与跨平台验收分别记录，
不能把实现完成解释为所有平台已发行验收。

## 聊天与文档

聊天正文使用 WebView，消息输入、审批、导航与窗口继续沿用现有 JavaFX 控件和主题。App Server 主动发送
已持久化的消息增量；网络重连或页面重建从已接收状态恢复，不重新提交原来的对话。

生成中可以切换会话，返回后会恢复当前任务的运行状态。历史恢复未完成或失败时暂时禁止发送，避免重复提交；
失败后可再次点击当前会话，或在会话列表按 Enter 重试。重复激活正在运行的会话不会重新启动任务。

消息输入框中 Enter 发送，Shift+Enter 在光标或选区处换行；Ctrl/Cmd+Enter 也可发送。
中文输入法选词期间不触发发送，发送不可用时保留草稿。

点击发送后，消息立即在聊天区显示“你 · 正在发送”，不必等待服务端启动请求及历史查询完成。
收到启动回执后显示“已发送”，权威用户消息到达时替换本地回显，避免重复显示；若回执未确认，
显示“发送未确认”并保留草稿。同一草稿重试复用原发送身份，切换对话不会把迟到的消息写入新会话。
实现原因和验收范围见 [发送交互修复记录](evidence/chat-send-interaction-2026-09-09.md)。

点击聊天中的附件、支持的文件引用或代码块下方的“查看代码”按钮，可以在右侧“文档”页查看；
“待处理”页仍显示当前审批与执行情况。
支持 Markdown、代码、纯文本以及 PNG、JPEG 和 GIF 首帧。文本按页读取，图片先验证格式和解码尺寸。
其他格式显示文件信息及不支持的原因；不将 PDF、Office 或网页当作已经支持的格式。

工作区文件显示的是打开时复制的不可变版本，重新打开才读取当前版本；消息和附件显示已引用版本。
文件读取必须能追溯到当前工作空间内的来源消息或受支持的工具结果，并且仍受当前权限限制。文档中的相对图片
与链接也要单独验证。附件没有明确的消息关联时，不推测工作区的同名文件。

页面加载或脚本异常时，宿主会自动重建一次，再使用原生简版显示。聊天、文档和图谱区域均可右键选择
“简版显示”或“重试显示”，页面正常加载后也可主动切换。这个恢复机制不能处理导致整个进程退出的 WebKit
原生崩溃。关闭文档、切换工作空间或连接重建会释放旧预览。

macOS 聊天与文档中的彩色 emoji 使用系统字体在后台离线绘制，绕开 WebKit 混排时的字形异常。
页面保留原始 Unicode 字符，复制和选择仍操作文字；不下载字体或图片，不修改消息记录。
流式分块会合并代理对、肤色、国旗和 ZWJ 组合。超出字素或资源预算、系统字体不可用时保留原字体显示。
验证范围和截图见 [彩色表情修复记录](evidence/chat-emoji-rendering-2026-09-09.md)。

## 后台任务

任务继续在现有 App Server、Schedule 和 Extension Job 体系中执行。在定时任务管理中查看调度时间、启停与
执行记录，在 Job 页面查看执行状态、回执和取消结果。桌面窗口不需要一直打开，但 App Server 必须仍在运行；
操作系统登录启动、睡眠唤醒和安装行为仍需对应平台验收。

活动任务的取消会先保存请求，当前步骤在安全检查点处理。页面显示“已请求取消”时，不等同于步骤已经退出；
已执行的副作用及未知结果仍按原有回执机制处理。错过的触发不补跑，前一次仍在执行时跳过重叠触发。

## 开启工作空间记忆学习

1. 打开当前工作空间的“后台记忆学习”，选择 Agent Role、Provider/模型和权限配置。
2. 勾选“明确启用后台学习”并保存。默认关闭；首次启用只扫描最近 30 天的已完成公开对话。
3. 在托管定时任务管理中调整名称、时间、时区与启停。默认每 6 小时触发；需要现在处理时，
   在“后台记忆学习”点击“立即执行一个批次”。
4. 在“批次审计”检查执行结果。未知结果阻止后续周期绕过该批次，必须明确重试或跳过。

一次学习最多处理 200 条证据、一次模型 Turn，使用 16000 输入 / 2000 输出 token 和 120 秒预算。
工具目录为空，学习输出不再作为下一次学习的对话来源。超大证据会记录跳过原因，不静默截断成新的事实。
启用后使用所选 Provider，可能按其规则产生调用费用；自动测试只使用固定模型替身。

学习执行配置统一在“后台记忆学习”中修改。通过通用定时任务选择学习任务时，执行选择应留空或与已保存配置一致；
低于上述固定上限的预算会明确报错，需要其他执行配置时应先修改学习设置。更宽的预算仍收窄到固定学习上限。

调度删除后不会因旧绑定重试而自动复活。如需重新建立，勾选“明确重新安排已删除的定时任务”。
绑定协调 Job 失败时，可使用“修复待绑定意图”明确提交修复。

重开学习配置会回显保存的审批策略、推理设置及角色、模型、权限的精确版本。引用版本失效或尚未加载时，
页面保留原引用说明并保持未选；需要明确选择可用配置后保存，不会自动改成最新版本。

## 审查记忆与图谱

默认学习策略为建议模式；只有明确选择自动低风险策略后才允许自动发布可逐字核验且满足策略的低风险事实。
摘要、推断与冲突进入人工审查。在“记忆冲突”中可选择保留旧
记忆、替换、合并或按条件并存；提交时会检查所选版本，发生并发变化会保留草稿并要求刷新。

存在待处理冲突引用的记忆需要先处理冲突再删除。历史数据中的冲突若引用了已删除或已替代记忆，
可以选择“保留旧记忆”拒绝候选并关闭冲突；该操作不会恢复已删除或已替代的记忆。

“记忆图谱”显示记忆节点和已确认关系，选中节点后在下方查看来源证据；支持筛选、查看历史和展开邻居。
首次最多显示 200 个节点，
每次扩展最多 50 个，单页累计最多 500 个节点和 1000 条边。位置与浏览选择只保留在当前页面，不影响其他客户端。
关系需要人工确认；记忆正文编辑后，关联到旧版本的关系退出当前投影，需要重新确认。

有效时间使用 ISO-8601，起始时间包含、结束时间不包含。自然语言条件只供人工判断，不会自动加入模型记忆检索。
被替代、已删除、时间失效及未确认的记忆不会当作当前有效记忆检索；旧搜索接口只返回有效且完全无条件的记忆，
不包含带时间区间或自然语言条件的记忆。
