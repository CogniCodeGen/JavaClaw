# Agent 会话、执行轮次与原子步骤

JavaClaw 的执行身份分为 `ThreadAgent → Turn → Step`。Thread 是长期任务，Turn 复用
AgentEngine 的 Run 状态机，Step 记录实际模型输入输出、工具操作及编排动作。工作区和用户
始终属于隔离键，不能仅根据显示标题或裸会话 ID 选择数据。

## 生命周期接口

`ThreadClient` 提供 `start/get/list/resume/archive/fork/delete/configure`，所有会话操作
都携带 `RunScope(workspaceId, userId, sessionId)`。`TurnId` 与原 `RunId` 一一对应；
`AgentClient.startTurn/resumeTurn/interruptTurn/getTurn` 是兼容现有 Run 内核的明确命名。

同一会话只执行一个活动 Turn，其余请求可靠排队。审批和输入等待延续原 Turn。
`AgentClient.beginTurn` 为现有 Loop、SDD、GraphEngine 创建持久协调 Turn，调用者必须等待
`ManagedTurn.ready()`，并在退出时关闭句柄。模型推理仍只能经统一 Spring AI 网关执行。

Thread 保存目录、模型、权限和项目指令；每轮使用不可变配置快照。更改 Thread 配置不会
改变正在执行的 Turn。有效权限受到宿主、Thread、Turn 和父级委派的共同限制。

## 历史与记忆

H2 的 Thread/Run 事件是原始执行记录。事务 outbox 将其投影到 `data/rollouts/` 下的
JSONL 文件和 EclipseStore 会话图谱；目录分量使用隔离键的安全编码，避免路径穿越与名称冲突。
投影失败会保留任务以便重试，原始输入输出不会因模型上下文压缩而被截断。

个人习惯图按工作区和用户隔离，会话图再按 Thread 隔离。Agent 只检索自己的会话图和
个人习惯图，子 Agent 通过明确的任务输入和结果摘要交换信息。向量不可用时仍能按关键词、
近期原文和来源关系检索。模型生成内容、分支副本和委派摘要不会成为新的用户习惯证据。

后台记忆模型任务拥有独立的维护 Turn，并保留原始证据身份；维护执行不再次触发提炼。
记忆中心提供个人习惯、指定会话与只读历史待归属视图。插件读取也必须选择授权范围。

## 分支、删除与旧数据

分支以选定终态 Turn 的事件水位为边界，复制历史与执行记录并生成新身份。分支拥有自己的
数据，后续独立演进，源会话删除不会破坏分支。旧记录缺失的模型/工具步骤不会被补造。

删除先设置持久墓碑并停止接单，再取消从属执行、关闭图谱写入口和资源租约、清理数据。
父会话的从属子 Agent 一并删除，独立分支和已晋级的个人习惯保留。迟到事件与旧 UI 快照
不能重新建立已删除会话。“清空对话”通过创建新会话身份实现。

工作流与 SDD 的业务检查点、文档和验收缓存同样遵守所属会话的删除墓碑。删除会等待
活动工作流驱动退出，再释放扩展资源；未打开的工作区也会通过根级清理入口移除持久数据。

升级时原聊天与 Run 按现有来源导入。记忆中能确定会话来源的内容迁入对应图谱；无法确定
来源的内容留在历史待归属区域，默认不参与召回。迁移可重复执行，不将未知任务事实自动
升级成个人习惯。

## 验证

针对性测试覆盖会话隔离、队列、审批和重启恢复、步骤记录、outbox 重试、历史分支、删除
竞态与旧数据导入。完整检查使用：

```bash
mvn clean -Pui-test verify
```
