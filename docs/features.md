# JavaClaw 整体功能

JavaClaw 是基于 JavaFX 与 AgentScope 的多智能体桌面工作台，将对话、方案研讨、持续推进、
工程任务托管和可复用工作流放在同一个应用中。它可以调用浏览器、代码工程、命令行、邮件、
系统与桌面自动化等工具，并提供长期记忆、知识库、技能、MCP、插件和定时任务。

## 工作模式

| 模式 | 核心行为 | 典型场景 |
|---|---|---|
| 普通模式 | 主编排器按意图选择专家、工具和技能，流式返回结果 | 日常问答、网页操作、代码修改、邮件与桌面任务 |
| 规划模式 | 多位专家围绕同一问题讨论并汇总方案 | 技术选型、方案设计、多角度评审 |
| 循环模式 | 多轮推进同一目标，以客观标准核验进展和完成状态 | 修复到测试通过、等待 CI、持续打磨产物 |
| 托管任务 | 按提案、规格、设计、拆解、实现和验收推进长任务 | 有明确验收标准的工程改造 |
| 工作流模式 | 执行已经校验和发布的状态图，支持检查点恢复 | 固化重复流程、条件分支和人工输入链路 |

模式共享同一套工具授权、执行资源、工作区和审计边界。用户可以在聊天顶栏切换模式，也可以
从侧边栏进入托管任务与工作流中心。

## 模型与智能体

支持 OpenAI 兼容 API、DashScope、Anthropic、Gemini 和 Ollama。模型地址、模型名、API Key、
思考模式与分级模型可以在设置中维护；凭据加密后写入 H2。嵌入模型独立配置，供长期记忆和
知识库共用。

主编排器可以调用内置或自定义专家：

| 专家类型 | 主要能力 |
|---|---|
| 编程与评估 | 代码分析、方案设计、任务质量判断 |
| 知识 | 知识库检索、概念解释和带来源上下文的回答 |
| 网页 | Playwright 导航、读取、交互、截图、Cookie 和 PDF |
| 邮件 | SMTP 发信、IMAP 收信、搜索和回复 |
| 系统与桌面 | 文件、键鼠、截图以及基于视觉定位的软件操作 |
| 通知与命令 | 多渠道推送、受控命令执行 |

工具、技能和 MCP 能力按本轮意图选择；路由失败时采用安全回退。关键信息缺失时，智能体通过
澄清卡片询问用户。普通模式还包含目标拆解、执行监控、中段评估和计划修正。

## 对话与桌面体验

- 多会话侧边栏、历史持久化、自动标题和工作区切换；
- 流式输出，思考过程与正式回复分区展示；
- 原生 Markdown、代码块、表格、链接、图片和复制操作；
- 图片、文档与 PDF 附件，支持图片描述和 OCR；
- 图片查看器、快捷键帮助、非阻塞 Toast 和统一确认弹窗；
- 主题、字体和外观设置在所有窗口即时生效；
- 系统托盘、关闭时最小化、单实例唤起和安全退出 watchdog。

## 工具与外部集成

### 浏览器

Playwright 提供页面导航、无障碍快照、元素引用、点击、输入、键盘、滚动、等待、多标签页、
Cookie、JavaScript、截图和 PDF。BrowserContext 按会话隔离，避免聊天、定时任务和托管任务
共享临时登录态。

### 代码工程与命令

- 按行读取、正则检索和 glob 文件查找；
- 唯一片段替换、按位置插入和项目根围栏；
- Maven、Gradle、npm、Go、Cargo、Make 等构建与测试；
- Git 状态、差异、日志和受确认保护的提交；
- argv 或 shell 进程、工作目录、输出上限、超时、中断和进程树清理；
- 托管场景的只读命令白名单与路径范围校验。

### 系统、桌面与媒体

系统工具提供受控文件、键盘、鼠标和截图操作。桌面自动化结合截图标注与 Java Robot 操作
本地软件。媒体能力支持图片查看、OCR、PDF 文本抽取，以及扫描页回退识别。

### 邮件与通知

邮件能力通过 SMTP/IMAP 收发、搜索和回复邮件。通知支持钉钉、企业微信、飞书、邮件与自定义
Webhook；连接配置与密钥由设置页统一维护。

### MCP 与站点账号

MCP 中心可以添加、导入、启停和检查多个 Server，发现的工具进入统一工具调用管线。站点凭据
按工作区加密保存，可维护同站点多账号、会话绑定和浏览器登录态。

## 记忆、知识与技能

### 长期记忆

长期事实、对话情景、实体、人格和纠错记录由 EclipseStore 与 JVector 保存。每轮只召回与当前
问题相关的内容，不把全部历史重新注入模型。

- 轮后蒸馏、向量去重和旧事实软取代；
- 明确的“不是 X，而是 Y”纠错在当前轮生效并保留审计；
- 用户编辑、置顶和显式声明的事实受保护；
- 嵌入服务不可用时先保存纯文本，恢复后再回填向量；
- 记忆中心提供总览、事实、图谱、情景、实体、知识、人格、纠错和变更日志。

### 知识库

知识库支持导入文件、目录和文本，分为全局与工作区两个作用域。用户可以搜索、预览、启停、
删除文档或重建索引，知识专家按需执行 RAG 检索。

### 技能

技能保存可复用的操作方法和参考资料，支持查看、编辑、版本历史、回滚、打包和使用统计。
技能采用目录、正文、参考资料三级渐进加载。智能体可以提出新增或修改建议，按关闭、建议、
自动三种策略处理；用户修改过的技能不会被静默覆盖。

## 自动化与长任务

### 循环模式

每轮执行后记录完成提议、客观准则、进展证据、剩余事项和建议等待时间。只有执行体确认与
客观核验同时通过才结束。轮数、总时长、Token、连续失败和连续无进展构成停止护栏。

### 托管任务

托管任务采用提案、规格、设计、拆解、实现和验收六阶段。验收场景与任务清单可读、可恢复；
未通过的场景进入补做，超过重试或预算边界时转人工处理，不把未完成任务标记为成功。

### 工作流

工作流中心提供节点、连线、条件、错误边、重试、撤销重做、校验、发布和运行历史。执行过程
逐节点落检查点，副作用节点恢复执行前重新确认。系统内置流程以只读图复用相同运行语义。

### 定时任务

支持固定间隔、每日和 Cron。调度线程只负责触发，任务正文进入托管执行器；任务定义、启停状态
和执行结果按工作区持久化。

## 工作区、数据和扩展

工作区隔离模型、配置、聊天、定时任务、插件启用状态、凭据、日志、浏览器状态、知识和记忆。
切换工作区时创建候选 Spring 子 Context；成功后替换旧 Context，失败则恢复原工作区。

默认数据根为 `data/`：

- `.javaclaw-format` 标识数据格式版本 3；
- `javaclaw.mv.db` 保存结构化数据；
- `knowledge/`、`memory-stores/`、`skills/`、`logs/` 和 `screenshots/` 保存文件资产；
- 测试使用 `target/test-data` 或 `target/ui-test-data`，不会写入真实数据。

Plugin API 3.0 提供能力授权、私有存储、统一任务句柄和固定频率调度。插件按工作区启用，任务
使用宿主执行器与插件独立配额，卸载时回收自己的任务、资源和类加载器。

## 安全、可观测与可靠性

工具审核提供全自动、智能审核和手动审核。调用统一经过来源绑定、能力检查、风险确认、审计、
执行和结果映射；高风险命令与代码执行保留人工底线。项目根围栏、工作目录校验、凭据加密和
浏览器会话隔离限制副作用范围。

诊断中心记录执行轨迹并支持 JSON/CSV 导出。Token 与成本按会话和日期统计。后台任务提供状态、
完成结果、超时、取消和资源登记；工作区关闭或插件卸载会拒绝新任务、取消在途任务并等待释放。

## 快速开始

```bash
mvn clean compile
mvn javafx:run
```

主类必须是 `com.javaclaw.app.Launcher`。首次启动会引导配置模型；输入框使用 Enter 发送、
Shift+Enter 换行、Esc 取消当前生成。升级已有安装前请先阅读 [升级到 3.0](upgrade-3.0.md)。
