# JavaClaw 功能文档

> JavaClaw —— 基于 JavaFX 25 + JDK 25、采用 AgentScope Java 1.0.12 框架的多智能体桌面应用。
> 本文从**功能视角**说明 JavaClaw 能为用户做什么；架构与实现细节见《[设计文档](./agent-design.md)》与仓库根 `CLAUDE.md`。
> 最近更新：2026-07

---

## 1. 产品概述

JavaClaw 是一个面向桌面的多智能体助手：一个**主编排器**统筹一组**领域专家子智能体**，按用户意图自动委派任务、调用工具、自我评估并修正计划。它同时是一个可自学习、可扩展的平台——支持多模型提供商、长期记忆、技能进化、MCP 集成、插件、定时任务与跨工作区隔离。

**五种工作模式**覆盖不同场景：

| 模式 | 一句话定位 | 典型用途 |
|------|-----------|---------|
| 💬 **普通模式** | 主编排器层级委派专家完成工具型任务 | 日常对话、网页操作、收发邮件、系统/桌面自动化、代码改动 |
| 🧭 **规划模式** | 多专家围桌讨论、互相看到发言、汇总方案 | 方案设计、多角度分析、技术评审 |
| 🔁 **循环模式** | 反复推进同一目标，直到达成或触发停止 | 改到测试通过、等 CI 结果、盯状态变化、持续打磨产物 |
| 🛠️ **托管任务模式** | 按 OpenSpec 生命周期把一个工程需求做到验收 | 长时、有明确验收标准的开发/改造任务 |
| ⎇ **工作流模式** | 运行自己画好并发布的状态图 | 把跑通的流程固化复用，中断可从检查点续跑 |

> 顶栏下拉即可切换模式；托管任务与工作流中心也可从侧边栏进入。

## 2. 多模型提供商支持

内置支持 **5 种模型提供商**，可在设置中切换并分别配置 baseUrl / model / API Key：

| 提供商 | 说明 |
|--------|------|
| **OpenAI 兼容 API** | 任何 OpenAI 协议端点（含本地 LM Studio / vLLM / 第三方网关） |
| **DashScope** | 阿里云通义千问 |
| **Anthropic** | Claude 系列 |
| **Gemini** | Google Gemini |
| **Ollama** | 本地模型 |

- **思考模式**（`model.thinking.enabled`）对支持的模型（DashScope/Anthropic/Gemini 部分模型）开启推理过程展示。
- 所有 Agent 共享同一 HTTP 传输层，避免连接池耗尽。
- 嵌入模型单独配置（`rag.embedding.*`），由长期记忆与知识库共用。
- **首次启动向导**（OnboardingWizard）三步引导：选提供商模板 → 填 baseUrl/model/Key → 完成，每步可跳过。
- API Key 等凭据落库时加密存储。

## 3. 智能体与专家体系

主编排器根据用户意图，自动把任务委派给最合适的领域专家：

| 专家 | 擅长 |
|------|------|
| 🧑‍💻 编程专家 | 代码、技术、架构问题（纯推理，与编排器的代码工具同组协作） |
| 📚 知识专家 | 知识问答、概念解释、知识库检索（RAG） |
| 🌐 网页浏览专家 | 网页导航、搜索、表单操作、截图、PDF（Playwright 真实浏览器） |
| 📧 邮件专家 | 邮件收发、搜索、回复（SMTP/IMAP） |
| 🖥️ 系统专家 | 鼠标/键盘/文件/截图等系统操作 |
| 🪟 桌面自动化专家 | 操作任意桌面软件（跨平台，基于截图标注 + Robot） |
| 🔔 通知专家 | 钉钉/企业微信/飞书/邮件/自定义 Webhook 推送 |
| ⌨️ 命令行专家 | 执行命令行 |
| ✅ 任务评估专家 | 多步骤任务完成后的质量评分 |

> 还可在「智能体管理」中**自定义专家**（名称、系统提示词、能力、迭代上限），与内置专家一同参与编排。

- **按需加载工具**：编排前先用一次轻量模型调用判断本轮需要哪些工具/技能，只加载命中的部分，省上下文；判断失败自动回退全量。
- **自我优化能力（普通模式）**：编排过程内置目标拆解、执行监控、中段评估与计划修正闭环（GEPA），让智能体在任务过程中自我纠偏，而非一条道走到黑。
- **主动澄清**：遇到关键信息缺失或存在歧义时，智能体会弹出澄清卡片询问，而不是替用户擅自决定。

## 4. 工具能力

### 4.1 网页自动化（Playwright 真实浏览器）
导航、无障碍树快照与 `@ref` 元素引用、截图标注、点击/输入/键盘/滚动、等待、多 Tab 管理、Cookie、JS 执行、PDF 导出。可结合**站点凭据**自动登录。

### 4.2 系统与桌面自动化
- **系统工具**：鼠标、键盘、文件操作、截图。
- **桌面自动化**：通过截图打标（Set-of-Mark）+ Robot 输入，操作任意桌面软件，跨平台、不依赖 JNA。

### 4.3 代码工程
面向真实代码改动的专用工具集，比"整文件重写"更省 token、更不容易改坏无关部分：
- **读与检索**：按行区间读文件、正则内容检索（自动跳过 .git/node_modules/target 等）、按 glob 找文件——只读操作免确认。
- **精确编辑**：唯一片段替换与按行插入（命中 0 次或多次都会拒绝，先读后改）。
- **构建与测试**：自动探测 mvn / gradle / npm / go / cargo / make 等构建命令并执行，从输出中抽取关键错误与失败行成摘要（限定构建工具白名单，不做通用命令后门）。
- **git**：状态、diff、日志（只读免确认）与提交（需确认，提交信息不过 shell 直传）。
- **项目根围栏**：设定项目根后所有代码操作都被限制在其内，越界（含符号链接绕过）一律拒绝。

### 4.4 邮件
通过 Jakarta Mail 提供 SMTP 发信 / IMAP 收信、搜索、回复。

### 4.5 多渠道通知
钉钉、企业微信、飞书、邮件、自定义 Webhook，可在通知配置中分别接入。

### 4.6 命令行
执行 shell 命令；托管任务/循环内有只读命令白名单（ls/cat/grep 等）免确认直放，其余按风险确认。

### 4.7 媒体与 OCR
- **图片查看**：可缩放/拖拽的查看窗口，对话气泡中的图片双击即可放大。
- **OCR 识别**：图片走多模态识别；PDF 先抽内嵌文本，扫描件回退逐页渲染后识别。
- 发送的图片附件会先转成文字描述，供下游工具与子智能体使用。

## 5. 长期记忆

记忆不是"把聊天记录全塞回去"，而是**按当前问题向量召回最相关的少量内容**再注入。

- **统一记忆基座**：长期事实、对话情景、实体、人格、会话检查点都存在对象图 + 向量索引里（EclipseStore + JVector）。
- **自动沉淀与去重**：每轮结束后异步蒸馏值得长期记住的事实，相似内容合并而非重复堆积；新事实否定旧事实时旧的自动取代（软删除、留审计轨）。
- **显式纠错**：说「不是 X，而是 Y」这类明确更正会**当轮立即生效**——撤销旧记忆、写入更正、后续回答再冒出旧错误会被拦下（不会说出口，也不会写回记忆）。涉及外部公共知识的更正先标记为"存疑"，等核验后再升格。
- **习惯回顾**：跨多轮归纳重复出现的偏好为"习惯"，补足逐轮蒸馏只看单轮的盲区。
- **记忆图谱**：事实 / 情景 / 实体三类节点的关联网络，力导向可视化，支持类别筛选、聚焦深度、点击查看关联；已被取代或存疑的事实不入图。
- **记忆中心**（侧边栏 🧠）八个分区：总览（健康度仪表盘）、事实（分组/行内编辑/置顶/批量删除/手动新增）、记忆图谱、情景记忆、实体、知识库、人格（结构化编辑 + 注入预览）、变更日志（append-only 审计）。
- **降级不丢**：嵌入服务不可用时新记忆以纯文本暂存（记忆中心可见并有横幅提示），服务恢复后自动或一键「立即回填」重嵌入；此期间对话照常进行。

## 6. 技能系统（可自学习）

技能是智能体的「程序性记忆」，记录"遇到某类任务该怎么做"，可由用户编写、也可由智能体**自己沉淀与进化**。

- **技能中心**：浏览/编辑技能（名称、分类、标签、版本），查看使用统计、版本历史并可回滚，管理技能包。
- **三级渐进加载**：常驻只读目录 → 按需拉取单技能全文 → 再拉取单个参考文档，节省上下文 token。
- **自学习闭环**：智能体在对话/任务后自动蒸馏经验，或主动提议新增/修改技能，统一进入**待审提案**队列。
  - `skill.evolution.mode` 三态总闸：`off`（关闭）/ `suggest`（提案待审，默认）/ `auto`（自动落盘 + Toast 提示）。
  - **用户改过的技能受保护**：任何模式下都不会被智能体静默覆盖。
- **JShell 脚本**：技能可携带 `.jsh`/`.java` 脚本，由智能体按需运行（独立 JVM 进程隔离、超时与输出截断，执行前需确认）。

## 7. 知识库与 RAG

- 支持导入文件、文件夹、纯文本构建向量知识库，知识专家在对话中按需检索。
- **全局知识库**（所有工作区共享）与**工作区知识库**（仅当前工作区）两级。
- 记忆中心「知识库」分区可查看导入文档的分块、重建索引或删除。
- 切换嵌入模型时需保证 `rag.embedding.dimensions` 与模型实际维度一致，并清空旧向量库。

## 8. 循环模式

适合"一次不够、要反复推进到达成"的目标——补足普通模式的单轮人在环、托管任务的一次性、定时任务的无状态触发之间的空缺。

- **自动多轮**：每轮智能体推进一次并提交结构化汇报（是否完成 / 本轮小结 / 剩余事项 / 建议等待时长），上下文接力压缩后进入下一轮。
- **完成要双点头**：智能体自报完成**并且**客观核验通过（真跑命令、真查文件、真比对产出）才算完成，绝不默认放行；目标拆不出客观标准时自动启用模型验收员兜底。
- **停止护栏**：轮数、token 用量、总时长、连续失败、连续无进展任一触发即停；进展必须有状态变化为证据，换个说法复述不算。
- **两种节奏**：自驱（做完立刻下一轮，可由智能体自报等待时长）与定时轮询（固定间隔，适合等 CI、等邮件）。
- **首行指令**：`@loop interval=5m max=20 judge=on workdir=/path`（间隔 / 轮数上限 / 验收员 / 核验基准目录）。
- **状态面板**：实时显示轮次、验收标准通过进度、每轮决策与用量。
- 启动前若验收命令不属于只读白名单，会先请求一次授权，拒绝则不启动。

## 9. 托管任务模式（SDD 工程流程）

把一个工程需求当作一个 OpenSpec change，按生命周期推进到**可验收完成**：

```
提案+评审 → 规格(验收场景) → 设计 → 任务拆解+评审 → 实现(逐项勾选) → 验收+补做 → 归档
```

- **markdown 即真相**：需求/场景/任务清单都是可读的 markdown，进度 = tasks.md 勾选折叠。
- **绝不假完成**：验收由单点权威核验全部能力场景，未过即按未过场景补做；多轮仍不过则升级人工。
- **可暂停/恢复**：中断的任务降为「暂停」等用户手动续跑，不会自动烧 token；续跑从首个未完成项继续。
- **预算闸门**：可设任务级 token 累计预算，达限即停下等用户决定是否加预算续跑。
- **可视化界面**：环形进度 + 统计卡 + 六阶段流水线步进器 + 概览/验收场景/实现清单/实时日志四页签。

## 10. 工作流中心

把流程从"每次靠模型自己决定下一步"变成"按你画的图执行"。

- **可视化设计**：图自带开始/结束节点，可添加智能体、工具、条件分支、数据转换、人工输入、输出六类节点并连边；出口分普通边、条件边（按状态取值分流）与错误边，节点可配重试策略，图可配最大步数；编辑支持撤销/重做。
- **校验后发布**：先校验图的连通性与配置合法性，发布后即可在「工作流」模式里选中运行。
- **逐节点检查点**：每个节点执行前后落检查点；中断后可从运行历史续跑，有副作用的节点重跑前会再次征求确认。
- **运行可观测**：节点开始/结束事件实时回流到聊天区与运行列表，可随时取消或暂停。
- **工具边界**：自定义工作流节点只能使用本地工具组，远程 MCP 工具默认不开放。
- 内置的对话/研讨/循环/托管任务四条流程也以只读「系统图」形态跑在同一台引擎上，因此共享同样的阶段可观测性与检查点语义（系统图不可编辑）。

## 12. 定时任务

支持三种触发方式：**间隔**、**每日**、**Cron**。定时任务用独立的执行体运行（不复用交互会话，避免与聊天互相干扰），任务定义与执行记录持久化在全局数据库中并按工作区隔离。

---

## 13. 站点凭据与会话

按工作区管理站点账号/密码（密码加密存储），为 Playwright 浏览器自动登录提供凭据与持久化的登录态（`storageState`），下次直接复用免重复登录。

---

## 14. 工作区隔离与数据存储

可创建多个工作区分别对应不同项目/账号，切换工作区即整体重载配置、服务与界面。

- **结构化数据**（配置、聊天记录、定时任务、凭据、技能统计与提案、任务与规格文档、工作流定义与运行检查点、用量统计等）统一存在单个数据库文件 `data/javaclaw.mv.db` 中，按工作区字段隔离。
- **文件资产**（记忆与知识的向量库、截图、日志、浏览器 Cookie）按工作区分目录存放于 `data/` 下。
- 清库调试可直接删除 `data/javaclaw.mv.db`（会丢配置/聊天/任务，但不影响记忆与知识库）。

> 注：技能本体与版本历史是**全局**的（跨工作区共享），但技能使用统计与提案队列按工作区隔离。

## 15. 界面与主题

- **9 套内置主题**（2 深 7 浅）：emerald（默认）/ midnight / carbon / sapphire / ocean / plum / terracotta / honey / graphite，运行时实时切换、全局即时生效。
- 切换入口：聊天顶栏「风格」菜单、设置 →「外观 → 界面风格」、通用设置快捷下拉。
- **Markdown 气泡**：纯原生渲染，文字可选中复制、彩色 emoji、代码块自带复制按钮、链接点击开系统浏览器；流式输出按块增量刷新。
- 流式气泡渲染：思考过程与回复在同一气泡内分隔显示；同一工具的连续结果合并、不同工具新建结果块。
- 多媒体附件：支持发送图片、文档、PDF；图片会先转成文字描述供下游处理，也可双击放大查看。

## 16. 用量与成本追踪

按会话/日期统计 token 用量，估算人民币成本，并在流式过程中实时更新界面；额外统计**缓存命中率**（命中的 cached tokens 占比），帮助评估上下文复用效率。

## 17. 安全与确认机制

**总闸：工具审核模式**（聊天顶栏可快速切换，按工作区记住）

| 模式 | 行为 |
|------|------|
| 🤖 全自动 | 所有操作默认同意（少数高危通道仍保留人工确认） |
| 🧠 智能审核（默认） | 按风险等级 + 影响范围智能判定 |
| 🙋 手动审核 | 所有操作都需确认——连"仅通知"级别也升级为弹窗，且不吃任务级"同意全部" |

**智能模式下按风险分三档：**

| 档位 | 表现 |
|------|------|
| 🟢 通知放行 | 仅弹非阻塞 Toast，自动执行 |
| 🟡 弹窗确认 | 需用户点「允许本次 / 永久允许 / 拒绝」（超时默认拒绝） |
| 🔴 二次确认 | 关键操作需输入关键词二次确认 |

- 子智能体发起的确认请求会**透传给用户**，不会被静默跳过。
- 托管任务/循环内有只读命令白名单与轻量范围评估两道免人工通道，但越界操作仍会拦截确认；这类"放宽"只对托管场景生效，不会串染到普通聊天与定时任务。
- JShell 执行、高风险命令、命令白名单永久授权是人工底线，即使开了自动模式也仍需确认。

## 18. 插件系统

- 把插件 jar 放进全局 `plugins/` 目录即可被发现，在插件中心启停与卸载。
- **能力授权**：插件声明的能力（对话、记忆、定时、私有存储）等于权限申请，首次启用时弹确认，授权结果按工作区记住。
- 每个插件由独立运行时容器托管其线程与资源，私有存储互相隔离。

- **执行轨迹可视化**：展示多轮会话的执行轨迹。
- **导出**：可将轨迹导出为 JSON / CSV，便于排查与复盘。

## 附：快速上手

```bash
# 编译
mvn clean compile

# 运行（main class 必须是 com.javaclaw.app.Launcher）
mvn javafx:run
```

首次启动会弹出向导引导配置模型提供商；之后即可在聊天框输入需求，按 Enter 发送、Shift+Enter 换行、Esc 取消生成。
